### Installation

Install tda-project-planner and enjoy the experience.

1. Clone the tda-project-planner repository:

```sh
❯ git clone https://github.com/TheDarkArtist/tda-project-planner
```

2. Navigate to the project directory:

```sh
❯ cd tda-project-planner
```

3. Install the project dependencies:

```sh
❯ cd tda-project-planner
```

```sh
❯ bun i
```

### Usage

Run tda-project-planner using the following command:

```sh
❯ bun run dev
```

Navigate to http://localhost:3000 to start streaming videos.
